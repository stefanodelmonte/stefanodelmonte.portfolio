# stefanodelmonte.com

Portfolio personal desarrollado con [Astro](https://astro.build).

## Estructura

```
/
├── public/
│   ├── cv/                 
│   ├── img/                 
│   ├── CNAME                # Dominio personalizado
│   └── favicon.svg
├── src/
│   ├── i18n/                # Traducciones ES/EN
│   ├── layouts/
│   ├── pages/
│   └── styles/
├── .github/workflows/       # Deploy automatico a GitHub Pages
└── package.json
```

## Comandos

```bash
npm install          # Instalar dependencias
npm run dev          # Servidor de desarrollo (localhost:4321)
npm run build        # Build de produccion
npm run preview      # Preview del build
```
